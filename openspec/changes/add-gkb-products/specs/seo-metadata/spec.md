## MODIFIED Requirements

### Requirement: Шаблоны title

Title SHALL формироваться по шаблону своего типа страницы, если редактор не задал свой title в поле SEO:

- главная: «Газовые котлы Житомир — официальный представитель АТЕМ в Беларуси»;
- категория: «{Название категории} {Бренд категории} — купить в Беларуси | ГазКотелБел». Бренд категории задаётся у категории. Если он не задан, используется «Житомир»; у категорий товаров GKB это «GKB», у «Газовых колонок», где есть и АТЕМ, и GKB, — «ВПГ»;
- товар: «{Название товара} — {подзаголовок} | ГазКотелБел». Цены в title не выводятся: они публикуются только в прайс-листе;
- прочие страницы: «{Заголовок страницы} | ГазКотелБел».

В title MUST NOT быть повторов бренда, хвоста «gazkotelbel» и пустых разделителей. Название бренда MUST NOT стоять на категории, в которой нет ни одного товара этого бренда. Длина title SHOULD укладываться в 70 символов. Если шаблон не помещается, бренд в конце отбрасывается раньше содержательной части.

#### Scenario: Title товара

- **WHEN** открыта страница «Житомир-3»
- **THEN** title начинается с «ЖИТОМИР-3», содержит подзаголовок и не содержит цен

#### Scenario: Title категории котлов не изменился

- **WHEN** открыта категория «Газовые котлы»
- **THEN** title — «Газовые котлы Житомир — купить в Беларуси | ГазКотелБел»

#### Scenario: Title категории GKB

- **WHEN** открыта категория «Стабилизаторы напряжения»
- **THEN** title — «Стабилизаторы напряжения GKB — купить в Беларуси | ГазКотелБел»
- **AND** слова «Житомир» в title нет

#### Scenario: Title смешанной категории

- **WHEN** открыта категория «Газовые колонки»
- **THEN** title — «Газовые колонки ВПГ — купить в Беларуси | ГазКотелБел»

#### Scenario: Ручной title

- **WHEN** редактор заполнил поле «SEO title» у страницы «О производстве»
- **THEN** title страницы равен заполненному значению без добавлений

#### Scenario: Нет мусорного хвоста

- **WHEN** открыта любая страница сайта
- **THEN** title не содержит подстроку «gazkotelbelgazkotelbel» и не заканчивается на « -»

### Requirement: Description на каждой индексируемой странице

Каждая индексируемая страница SHALL иметь meta description длиной 120–170 символов. Description берётся из поля SEO, если редактор его заполнил. Иначе он строится по шаблону типа страницы. Шаблон товара включает мощность или диапазон мощностей, если у товара есть мощность в кВт, и «официальная гарантия». Цены в description не выводятся. Шаблон категории включает число моделей, диапазон мощностей (если он есть) и производителя товаров категории: «от официального представителя АТЕМ» для категорий «Житомир», «торговой марки GKB» для категорий GKB, АТЕМ и GKB вместе для «Газовых колонок». Description категории MUST NOT упоминать производителя, товаров которого в категории нет. Если шаблон даёт меньше 120 символов (например, у товара без мощности), у товара SHALL быть заполнено поле SEO description. Две индексируемые страницы MUST NOT иметь одинаковый description.

#### Scenario: Description категории без ручного текста

- **WHEN** у категории «Газовые котлы» не заполнено поле SEO description
- **THEN** description страницы категории сгенерирован по шаблону и содержит число моделей

#### Scenario: Description категории GKB

- **WHEN** открыта категория «Датчики угарного газа» без ручного SEO description
- **THEN** description содержит «GKB» и число моделей, а «АТЕМ» и «Житомир» в нём нет

#### Scenario: Description товара без мощности

- **WHEN** открыта карточка «GKB SN-500»
- **THEN** description длиной 120–170 символов, в нём нет «кВт»

#### Scenario: Уникальность

- **WHEN** скрипт аудита собирает description всех URL из sitemap
- **THEN** повторяющихся значений нет
