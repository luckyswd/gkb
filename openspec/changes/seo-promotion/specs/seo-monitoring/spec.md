## Purpose

Замер эффекта SEO-работ: базовый срез до изменений, повторяемый аудит после каждой выкладки, регулярный отчёт по позициям, трафику и скорости. Источники — ShefTools MCP, Яндекс Вебмастер, Google Search Console и Яндекс.Метрика.

## ADDED Requirements

### Requirement: Базовый срез

До первой выкладки SEO-изменений SHALL быть сохранён базовый срез в `openspec/changes/seo-promotion/baseline/`:

- Lighthouse (мобильный и десктоп) по контрольным страницам;
- мета-теги и JSON-LD всех URL из sitemap;
- число страниц в индексе Яндекса и Google;
- позиции по семантическому ядру из ShefTools MCP или Вебмастера;
- визиты из поиска за 28 дней из Метрики.

#### Scenario: Срез есть до выкладки

- **WHEN** первая SEO-правка готова к пушу в `main`
- **THEN** в каталоге baseline лежит срез с датой раньше этой выкладки

### Requirement: Скрипт аудита

В репозитории SHALL быть скрипт аудита. Он запускается одной командой против любого базового адреса и проверяет требования `seo-metadata`, `structured-data`, `crawl-indexing` и `ai-agent-readiness` по всем URL из sitemap:

- один title, description нужной длины и уникальный;
- canonical;
- robots;
- OG;
- разбираемый JSON-LD с обязательными сущностями;
- ровно один h1;
- alt;
- коды ответов;
- llms.txt и robots.txt.

Скрипт выдаёт отчёт со списком нарушений и ненулевой код выхода, если они есть. Lighthouse по контрольным страницам запускается отдельным флагом.

#### Scenario: Прогон после выкладки

- **WHEN** скрипт запускается против `https://gazkotelbel.com` после выкладки
- **THEN** он завершается с кодом 0 или перечисляет конкретные URL и нарушенные правила

### Requirement: Цели в Метрике

В Яндекс.Метрике SHALL быть настроены цели: клик по телефону, клик по email, переход на «Где купить?» и региональные страницы, отправка формы обратной связи, скачивание документации (PDF). Цели SHALL срабатывать на русской и английской версиях.

#### Scenario: Отправка формы

- **WHEN** посетитель отправляет форму обратной связи
- **THEN** в Метрике достигается цель «Отправка формы»

### Requirement: Регулярный отчёт

Раз в месяц, в течение трёх месяцев после выкладки, SHALL готовиться отчёт в сравнении с базовым срезом:

- страницы в индексе;
- позиции по кластерам ядра;
- клики и показы из Search Console и Вебмастера;
- поисковые визиты и цели из Метрики;
- Lighthouse и Core Web Vitals;
- найденные регрессы.

Отчёт строится по данным ShefTools MCP и вебмастеров и сохраняется в `openspec/changes/seo-promotion/reports/` (после архивации — в архиве изменения).

#### Scenario: Первый месячный отчёт

- **WHEN** проходит месяц после выкладки
- **THEN** есть отчёт с дельтами по каждой метрике относительно базового среза
