# product-documentation Specification

## Purpose
Руководства по эксплуатации, приложенные к карточкам товаров: какая редакция документа отдаётся посетителю, под каким названием она подписана и откуда файл физически загружается.

## Requirements

### Requirement: На карточках выложены руководства редакции 2026

Карточки товаров Житомир-3, Житомир-3 с ТЭНом, Житомир-10 и Житомир-5 SHALL отдавать руководство по эксплуатации редакции 2026. Прежние редакции (2021, 2022, 2023) MUST NOT быть доступны по ссылкам с этих карточек.

#### Scenario: Житомир-3

- **WHEN** посетитель открывает `/products/zhytomyr-3/`, вкладку «Документация»
- **THEN** в списке одна ссылка с подписью «Руководство по эксплуатации Житомир-3 2026»
- **AND** по ней скачивается PDF на 32 страницы с обложкой «ЖИТОМИР-3 … Руководство по эксплуатации»

#### Scenario: Житомир-3 с ТЭНом

- **WHEN** посетитель открывает `/products/zhytomyr-3-with-teno/`, вкладку «Документация»
- **THEN** в списке одна ссылка с подписью «Руководство по эксплуатации Житомир-3 2026»
- **AND** она ведёт на тот же файл, что и на карточке Житомир-3
- **AND** прежний документ «Паспорт-Житомир-3-электрогазовый 2022» в списке отсутствует

#### Scenario: Житомир-10

- **WHEN** посетитель открывает `/products/zhytomyr-10/`, вкладку «Документация»
- **THEN** в списке одна ссылка с подписью «Руководство по эксплуатации Житомир-10 2026»
- **AND** по ней скачивается PDF на 41 страницу редакции 2026

#### Scenario: Житомир-5

- **WHEN** посетитель открывает `/products/zhytomyr-5/`, вкладку «Документация»
- **THEN** в списке одна ссылка с подписью «Руководство по эксплуатации конвектор Житомир-5 2026»
- **AND** по ней скачивается PDF на 30 страниц редакции 2026

### Requirement: Руководства отдаются с домена сайта и открываются

Файлы руководств SHALL храниться в медиатеке сайта и отдаваться с `gazkotelbel.com` с кодом ответа 200 и типом `application/pdf`. Ссылка, ведущая на несуществующий или битый файл, считается невыполненным требованием.

#### Scenario: Ссылка рабочая

- **WHEN** запрашивается URL любого из четырёх руководств
- **THEN** сервер отвечает `200` и `Content-Type: application/pdf`
- **AND** размер ответа совпадает с размером загруженного файла

#### Scenario: Документ открывается целиком

- **WHEN** посетитель открывает скачанный файл
- **THEN** PDF открывается без ошибок, и число страниц совпадает с исходником, который прислал производитель

### Requirement: Сводная страница документации показывает те же редакции

Страница `/documentation` SHALL показывать для этих четырёх товаров те же названия документов и те же ссылки, что и карточки товаров — отдельного ручного обновления она требовать не должна.

#### Scenario: Список на сводной странице

- **WHEN** посетитель открывает `/documentation`
- **THEN** в блоках Житомир-3, Житомир-3 с ТЭНом, Житомир-10 и Житомир-5 стоят подписи «… 2026»
- **AND** ссылки совпадают с теми, что на карточках товаров

### Requirement: Прежние редакции сохраняются в медиатеке

Файлы прежних редакций SHALL оставаться в медиатеке сайта и быть доступны по своим URL — чтобы откатиться можно было переключением поля, а не восстановлением из резервной копии.

#### Scenario: Старый файл на месте

- **WHEN** запрашивается URL прежнего руководства любого из четырёх товаров
- **THEN** сервер по-прежнему отвечает `200`
